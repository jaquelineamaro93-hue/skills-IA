# skills-IA

Skills para Claude Code e Codex, construídas e testadas em projetos reais por **Jaqueline Amaro**.

| Skill | O que faz |
|---|---|
| [`ai-avatar-video`](ai-avatar-video/) | Reels verticais com o seu avatar de IA falando com a sua própria voz clonada: identidade fiel, 5 ângulos, voz natural sincronizada à boca com autocorreção, cards, CTA e música. |
| [`complex-data-analysis`](complex-data-analysis/) | Análise de dados investigativa: 6 lentes não-convencionais, checagem anti-pareidolia, oportunidades priorizadas, gráficos e relatório com nível de confiança. |
| [`whatsapp-utility-templates`](whatsapp-utility-templates/) | Templates UTILITY do WhatsApp Business (Meta) prontos para aprovação: texto, variáveis, botões, payload JSON e checklist. |

## Plugins (Claude Cowork e Claude Code)
| Plugin | O que faz |
|---|---|
| [`sales`](sales-plugin/) | 36 skills de vendas: prep e resumo de calls, follow-up, pesquisa de contas, deals, pipeline, forecast, renovações e higiene do CRM. |
| [`engineering`](engineering-plugin/) | Standup, code review, arquitetura (ADR), debug, incidentes, deploy checklist, testes e documentação técnica. |

Instalação dos plugins no Claude Code:
```bash
claude plugin marketplace add jaquelineamaro93-hue/skills-IA
```
```bash
claude plugin install sales@skills-ia
```
Os plugins são obras derivadas de código aberto (Apache 2.0, ver `LICENSE` e `NOTICE` de cada um).

Cada pasta de skill é completa: `SKILL.md` (o fluxo), `references/` e, quando precisa, `scripts/` e `examples/`.
O README de cada skill traz o **checklist do que você precisa ter antes de começar** (contas, programas e materiais) e a instalação.
