# Jornada de ponta a ponta e contexto do projeto

## Jornada do cliente
Uma coluna por etapa (do primeiro contato até a recompra ou saída). Linhas:
| Linha | O que escrever |
|---|---|
| Sentimento | Como o cliente se sente (pode usar uma escala de 1 a 5) |
| Citações reais | Frases de clientes (pesquisa, atendimento, avaliações) |
| Pontos de contato e canais | Onde acontece: site, app, WhatsApp, e-mail, loja, telefone |
| Tarefas do cliente | O que ele precisa fazer |
| Dores | O que atrapalha |
| Oportunidades (CRM / CX) | O que a área pode fazer ali (mensagem, automação, benefício, integração) |
| Momento da verdade | A etapa que, se der errado, quebra a jornada (marque com ★) |
| Métrica | Como medir a etapa |
| Duração da etapa | Quanto tempo o cliente fica nela |

**Dica de quem já fez:** jornadas feitas só com olhar de CX esquecem os canais. Inclua a linha de canais: é ela que
mostra onde o CRM pode agir.

**Momento da verdade:** o instante em que o cliente decide se a experiência valeu. Exemplos: o cabeleireiro no
corte, o médico no diagnóstico, a entrega do primeiro pedido. Pergunta: "Quais momentos não podem dar errado?"

Perguntas para levantar a jornada: quem é a persona e o que ela vive; qual o momento do negócio; o que está funcionando
em cada etapa; quais são os gargalos e a causa-raiz; qual o impacto financeiro das experiências ruins.

## Contexto do projeto (quadro no Miro ou na planilha)
| Bloco | Pergunta |
|---|---|
| Sobre o projeto | Qual o objetivo, com número? ("reduzir churn em 15%") |
| Dados que existem | Que dados temos hoje e onde estão? |
| Ferramentas e sistemas | ERP, CRM, automação, data lake, atendimento... |
| Fora do escopo e premissas | O que não vamos fazer; o que estamos assumindo (ex.: LGPD) |
| Como o cliente se comporta hoje | O que ele faz de verdade |
| Como deveria ser | O cenário ideal |
| Dores da área | O que trava o time |
| Partes interessadas | Quem precisa participar, aprovar ou ser informado |
| Necessidades | O que precisa ser construído |
| Integrações | Que sistemas precisam conversar |
| Entregáveis | O que vai existir no final (dashboard, régua, portal...) |

Sem este quadro, cada área entende uma solução diferente.
