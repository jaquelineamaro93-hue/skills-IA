# Fases do ciclo e métricas: INPUT x OUTPUT

## Fases
Divida o ciclo do cliente em 3 a 4 fases. Exemplo para CRM:
| Fase | Público | Pergunta |
|---|---|---|
| Captação | novos clientes / leads | Como trazer e converter? |
| Maximização de valor | clientes ativos | Como fazer comprar mais e mais vezes? |
| Retenção / recuperação | sem compra há muito tempo, saindo | Como segurar e trazer de volta? |

Outras áreas: CX (contato → resolução → pós-atendimento); growth (aquisição → ativação → retenção → indicação);
produto (descoberta → ativação → hábito → expansão).

## INPUT x OUTPUT
| | INPUT | OUTPUT |
|---|---|---|
| O que é | o que o time controla diretamente | a consequência dessas ações |
| Exemplo (CRM) | taxa de abertura, taxa de clique, clientes engajados por semana, réguas ativas | LTV, receita por canal, churn, ticket médio |
| Usar para | gerir a rotina, saber se o trabalho está sendo feito | saber se o trabalho está dando resultado |

Essa separação existe para não confundir causa com resultado. Se o OUTPUT não se mexe com o INPUT subindo, a
hipótese entre os dois está errada: hora de revisar a estratégia, não de cobrar o time.

## Camadas de indicador em cada fase
1. **KPI principal de OUTPUT** (1 ou 2 por fase)
2. **KPI principal de INPUT** (1 ou 2)
3. **Indicadores secundários** (apoio: conversão por canal, frequência, recência)
4. **Indicadores de saúde** (o que não pode piorar: reputação do e-mail, NPS, opt-out, custo por contato)
5. **Ações prioritárias**

## WAU de CRM (exemplo de KPI de input)
WAU é "usuários ativos por semana". Adaptado para CRM: **clientes que se engajaram com os canais de CRM na semana**
(abriram, clicaram, responderam). Ele mede se a comunicação está viva. O output correspondente é o LTV (ou a receita
gerada por clique ou abertura). Adapte ao produto: em app, ativos no app; em B2B, contas com interação no mês.

## Perguntas que provocam
- Qual métrica o time consegue mexer amanhã? (input) Qual só se mexe em meses? (output)
- Se este input dobrar, por que o output deveria subir?
- Existe dado para medir isso hoje? Onde?
