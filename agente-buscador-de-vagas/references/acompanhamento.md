# Acompanhamento de candidaturas e conversão

## Planilha
| Coluna | Para que serve |
|---|---|
| Data de envio | Quando a candidatura foi feita |
| Vaga | Cargo, como está no anúncio |
| Empresa | Nome, ou "confidencial" |
| Link | Link original da vaga |
| Modelo e local | Remoto, híbrido ou presencial, e a cidade |
| Salário | Só se divulgado; senão, em branco |
| Match | Porcentagem estimada pela IA |
| Tipo de vaga | Para cruzar com o retorno |
| Status | Candidatei, entrevista, aprovada, recusada, sem retorno |
| Último contato | Data da última resposta ou ação |
| Dias sem retorno | Calculado |
| Próximo passo | O que falta fazer |

## Indicadores
- **Taxa de entrevista** = candidaturas que viraram entrevista ÷ candidaturas enviadas.
- **Taxa de aprovação** = entrevistas que viraram aprovação ÷ entrevistas.
- **Retorno por tipo de vaga** = taxa de entrevista, separada por tipo de vaga.

## Como ler
- Com poucas candidaturas (menos de 10), os números ainda não dizem muito. Espere algumas semanas.
- Candidatura sem retorno em 15 dias: vale um follow-up. Em 30 dias: revise o status.
- Se um tipo de vaga tem muitas candidaturas e nenhuma entrevista, ajuste o currículo ou os critérios antes de insistir.
