# Agente buscador de vagas

Monta um agente que busca vagas todo dia a partir do seu currículo, filtra pelos seus critérios, dá uma nota de compatibilidade e acompanha o retorno das candidaturas.

## Checklist: o que você precisa antes de começar
- [ ] Currículo atualizado em PDF
- [ ] Seus critérios: cargos, senioridade, modelo, cidade, idioma e o que não quer
- [ ] Pisos salariais de CLT e PJ, se quiser usar o filtro
- [ ] Uma IA com busca na web e tarefas agendadas
- [ ] Uma planilha para as candidaturas

## Como usar
1. Leia `SKILL.md`.
2. Copie os quatro textos de `references/passos-prontos.md` na ordem.
3. Monte a planilha com `references/acompanhamento.md`.
4. Guarde o resumo diário para comparar a conversão semana a semana.

Versão guiada, sem precisar copiar nada: [jaquelineamaro.com.br/agente-de-vagas](https://www.jaquelineamaro.com.br/agente-de-vagas/).
